---
name: Kindergarten name ambiguity
description: Clarify abbreviated Rakkerungan names rather than inferring the kindergarten from earlier shifts.
---

Treat Rakkerungan Barnehagedrift and Rakkerungan Gårdbarnehage as separate destinations. An abbreviated request for «Rakkerungan Barnehage» does not authorize choosing Gårdbarnehage based on an employee's previous shifts.

**Why:** The user corrected an assignment that used the employee's earlier workplace to resolve an abbreviated kindergarten name. The intended destination was Barnehagedrift, not Gårdbarnehage.

**How to apply:** Search both names and clarify an ambiguous destination before assigning. A previous shift is supporting context, not confirmation of the requested workplace. When correcting the destination, preserve existing shift identities, times, approvals and payroll fields.
